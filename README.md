# 姓名判断 〜五格剖象法〜

漢字・かなで名前を入力すると、熊崎式（五格剖象法）で姓名判断するWebツール。**漢字が筆順どおりに描かれて画数がカウントアップする**アニメーション付き。仕上げに「手相詩人 心之介。」風の鑑定トークと、色紙に一行詩をしたためる演出まで。**依存パッケージ・APIキー不要。**

## 起動方法

**1. スラッシュコマンド（推奨）**

Claude Code / Codex で `/seimeihandan` と打つ。ローカルサーバが立ち上がり、ブラウザが自動で開く。

**2. コマンドで直接**

```bash
node bin/cli.js
```

`http://localhost:4578`（使用中なら次の空きポート）でブラウザが自動で開く。

**3. ダブルクリック**

`index.html` をダブルクリックでも動く（オフライン可）。ただし「AIにじっくり鑑定してもらう」ボタンだけはローカルサーバ経由（codex CLI）が必要。

## できること

- **五格**（天格・人格・地格・外格・総格）の自動計算
  - 一字姓・一字名の**霊数**処理（天格/地格に+1、総格には含めない）
  - 82画以上は81数理に還元
- **81数理**の吉凶（大吉〜大凶）と意味の解説
- **三才配置**（天・人・地の五行の相生・相剋）
- **陰陽配列**（奇数=陽○ / 偶数=陰●）
- **筆順アニメーション**: KanjiVG の筆順データで漢字が一画ずつ描かれ、画数がカウントアップ。部首補正（＋n画）も演出付きで表示
- **心之介。風鑑定**: 明るい関西弁の鑑定トーク（オフライン生成）→ 一転して静かに、色紙に一行詩をしたためる演出
- **AI鑑定**: codex CLI（サブスク）経由で、心之介。風のより深い鑑定文を生成（`/api/reading`。四柱推命ツールと同方式）

## 画数の数え方（2モード）

| モード | 内容 |
|---|---|
| **旧字体・伝統画数**（既定） | 熊崎式の本流。旧字体に変換（恵→惠、沢→澤 等282組）し、部首は元の字の画数で数える（さんずい=水4画、くさかんむり=艸6画、しんにょう=辵7画、こざとへん=阜8画、おおざと=邑7画、にくづき=肉6画 等13種を自動判定） |
| **新字体・実画数** | 普段書いている字の筆数どおり |

画数の数え方は流派差が大きい領域のため、**適用した補正はすべて画面に内訳表示**する（例:「藤 18画 ＋3画 くさかんむり→艸(6画)」）。

## データソース

- **画数辞書**: [KANJIDIC2](http://www.edrdg.org/)（EDRDG、約13,000字）。KanjiVG収録字は「実際に書く筆数＝パス数」を優先（アニメの筆数と表示画数が常に一致）
- **筆順**: [KanjiVG](https://kanjivg.tagaini.net/)（CC BY-SA 3.0, © Ulrich Apel）。常用・人名用・頻出漢字＋かな＋旧字体 約3,350字を同梱
- **かな画数**: ひらがな・カタカナ（濁点+2、半濁点+1）
- 再生成する場合はスクラッチパッドの `gen-data.js`（KANJIDIC2 + KanjiVG から `js/data/*.js` を生成）

## 「心之介。」風の根拠

実在の占い師「手相詩人 心之介。」（古舘プロジェクト）の公開情報（Wikipedia・占いTVニュースのインタビュー・事務所プロフィール）から文体を設計:

- 「占いをポップに身近に」。一人称「僕」、関西弁まじりの軽快トーク、「！」「（笑）」
- 「あなたは○○タイプ。だから、△△だともっと輝ける」という**決めつけで終わらせない提案の型**（本人の言明）
- 口癖「人生を人に決められてたまるか！」
- 鑑定の締めに筆で色紙に**短い一行の書**（例「日々新たな自分に」）を書いてプレゼントするスタイル。喋りは陽、書は静
